# Davy Tao Research Pages

Research project pages published at [research.davytao.me](https://research.davytao.me/).

## Projects

- [SkelMo](https://research.davytao.me/skelmo/) - Universal Skeletal Motion Generation for 3D Rigged Shapes

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/skelmo/`.

## Deployment

This repository is published with GitHub Pages from the `main` branch. Its custom domain is configured by the root `CNAME` file. DNS should point `research.davytao.me` to `MOMOYATW.github.io`.
