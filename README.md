# SkelMo Project Page

Official project page for **SkelMo: Universal Skeletal Motion Generation for 3D Rigged Shapes**.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

This repository is intended to be published with GitHub Pages from the `main` branch at:

`https://research.davytao.me/skelmo/`

The custom domain is configured on the `MOMOYATW.github.io` user site. This project repository should not contain its own `CNAME` file.
